Level 0

Context diagram

The whole application as one process. Every flow into Denodo and the statement archive is a read; nothing in BankSystem writes to a bank system of record.

Level 1

Main processes

Every /api call except login passes through 2.0, which checks the bearer token and hands back a refreshed one past the halfway mark. The left bar is the route from 2.0 to the enquiry processes and back. The right bar gathers the archival reads of 3.0 to 7.0, each filtered on the banking date from D3. The UI keeps the token in sessionStorage and sends Accept-Language, which picks the English or Arabic name column.

Level 2

1.0 Authenticate operator

If the directory cannot be reached, 1.2 can fall back to local users (BANK_LDAP_FALLBACK). A wrong-password answer from the directory is final. Every signed-in user currently gets one interim admin authority.
